# Scoop logo

The Scoop logo is David's scoop character with the name "scoop". It comes in two styles, built from the same shapes:

- **Tidy** is the main style. The name has pink letters and white o's inside a mauve outline. Use it by default, on websites and everywhere else.
- **Solid** is the fallback. The name is plain mauve with no outline. Use it only where Tidy cannot work.

David chose this on Nov 26, 2026. `sheet.png` shows every file at full size and at small sizes.

## Files

| Layout | Tidy (default) | Solid (fallback) | Use it for |
| --- | --- | --- | --- |
| Lockup | `scoop-lockup-tidy.svg` | `scoop-lockup-solid.svg` | The main logo: landing page, social cards, stickers |
| Row | `scoop-lockup-tidy-row.svg` | `scoop-lockup-row.svg` | Site headers, email footers, any wide and short space |
| Wordmark | `scoop-lockup-tidy-wordmark.svg` | `scoop-lockup-wordmark.svg` | Places where the character is already shown, or does not fit |
| Icon | `scoop-lockup-icon.svg` | same file | App icon, Chrome extension button, favicon at 32px and up |

Every file except the icon has an `-on-cream` copy with a cream background in place of pink.

## When to use Solid

Tidy is the default. Switch to Solid only in these cases:

- **The logo is small.** Below the Tidy minimum widths in the table further down, the outline closes up and the name becomes a blob.
- **Only one or two colours are available.** Tidy needs pink, mauve and white. Solid needs mauve and a background.
- **The outline cannot be reproduced.** Examples are embroidery, engraving, a stamp or low-resolution print.

## Colours

| Name | Hex | Used for |
| --- | --- | --- |
| Pink | `#FFABDA` | Background, and the letters s, c and p in Tidy |
| Mauve | `#9F527C` | The character, the outline, and the Solid name |
| White | `#FFFFFF` | The eyes, and the o's in Tidy |
| Cream | `#FFF6EE` | Alternative background |

Contrast, worked out from the hex values:

- Mauve on pink is about 3:1. That is enough for a logo and large type, and too low for body text.
- Mauve on cream is about 5:1.
- White on mauve is about 5.3:1.

## What changed from David's original

The source is `../lockup-david-v1.svg`. The character and the letters are his shapes, unchanged. Only size, position and colour differ.

- **The name is bigger.** It is 25% larger in the Tidy lockup and 45% larger in the Solid lockup.
- **The eyes look at the name.** Both eyes moved 64 units left and 52 down, towards the notch.
- **The pink halo stroke is removed.** It did not separate anything, because the name never touches the character, and it showed as a pink ring on any background that was not pink.
- **The canvas is cropped.** Each file has an even margin around the artwork: 190 units for the lockups and rows, and 150 for the wordmarks.

## Known gaps

- **No single-colour versions.** There is no all-black or all-white file yet.
- **No transparent versions.** Every file has a pink or cream background.
- **The Tidy "p" hangs below the tail.** In the Solid lockup the bottom of the "p" lines up with the tip of the tail. In the Tidy lockup it sits about 100 units lower.
- **The character's shape is untouched.** It can read as a bird or a map pin before a scoop.
- **The name is not checked.** The trademark and name-clash check for Scoop is still open.

## Rebuilding

Every SVG and `sheet.html` are generated by `build.py` from the original lockup:

```bash
python3 build.py
```

Change sizes, positions or colours in `build.py`, not in the SVG files, or the next build will overwrite the edits. `sheet.png` is a screenshot of `sheet.html`.
