Connect an agent

Any agent that speaks MCP can use your library.

  1. Copy the address above.
  2. Add it as an MCP server in your agent's settings.
  3. Sign in when your browser opens. Each agent gets its own access, which you can end here at any time.

What an agent can do

Almost anything. Agents ask you first, and you can undo whatever they change.

  • Search, read, tag and describe your saves
  • Rename, merge, reorder, archive and delete saves, tags and projects
  • Fill projects, and report how each save was used
  • Let a sender out of quarantine
  • Use a tool you have not approved
  • Edit your own notes, or erase anything for good
  • Connect agents or change sources and settings
